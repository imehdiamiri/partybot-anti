# Tool picture icons

Built-in imagegen generated these silver/ivory/graphite picture-style icons.
PNG cutouts (not SVG), 256x256, true RGBA. Local exterior-background extraction
and downsampling were explicitly approved on 2026-09-07 after the generator
returned baked checkerboards. No image API fallback was used.

Prompt set: minimal premium vector-like picture illustration, softly dimensional
matte ivory/silver/graphite, restrained shading, simple silhouette, centered
isolated object, no frame, badge, floor, text, logos or outer shadow.
Subjects: die with dark pips; upright bottle with blank label; hourglass with
metal caps and sand; silver coin with embossed diamond; two person busts joined
by a double arrow; six-segment decision wheel with a top pointer.

All six PNGs are statically bundled for web, Android and iOS.
